# [НАЗВАНИЕ МАГАЗИНА] — демонстрационная витрина

Статический сайт без сборки и внешних библиотек. Каталог, фильтры, избранное, корзина и демо-оформление работают в браузере. Заказы не отправляются, оплата не подключена.

## Как открыть

Запустите локальный сервер из этой папки:

~~~powershell
python -m http.server 8000
~~~

Затем откройте http://localhost:8000. Можно также открыть файл index.html напрямую.

## Где менять данные

- app.js — контакты в CONFIG и примеры устройств в PRODUCTS: цены, остатки, варианты, состояние, аккумулятор, комплект и срок гарантии.
- index.html — заголовки, описания магазина, условия, доставка, оплата, ответы и отзывы.
- styles.css — цвета, расстояния и адаптивная раскладка.
- assets/ — изображения. Замените файлы, сохранив имена, или обновите пути в PRODUCTS.

Квадратные скобки в тексте ([ГОРОД], [АДРЕС], [ТЕЛЕФОН] и другие) — места для персонализации. Для подключения телефона и ссылки на мессенджер обновите CONFIG в начале app.js.

Все товары, характеристики, остатки, цены, отзывы и сроки в витрине приведены для демонстрации. Прежде чем публиковать магазин, замените их на актуальные сведения и утверждённые условия.
